# 一场戏：雨夜酒馆

把下面几行依次粘进输入框（`@` 后面换成你自己的路径）。

```text
/tavern on
/tavern card @D:\deepseek\chat\dsh-storyteller\examples\角色卡-艾琳.json
/tavern set persona 一个刚进城的外乡人，身上只有一把旧刀，刀鞘上刻着别人的名字
/tavern set scene 雨夜的酒馆。后厨门开着，风把灯吹得直晃；门边站着两个人，其中一个在滴水
/tavern style tone=冷硬，带一点戏谑
/tavern dice on
```

开场第一句自己给，别让模型替你选：

```text
我推门进去，把刀放在吧台上，说：来壶热的。
```

之后就是来回打。三个回合后可以补一句人设里藏着的钩子：

```text
我把刀鞘转过来，让那行刻字对着她。
```

想换场：

```text
/tavern set scene 后半夜，后厨。灶上还温着一副没人动过的碗筷
```

想看模型到底拿到了什么：

```text
/tavern preview
```

收尾：

```text
/tavern reset          # 清这一场，角色卡留着，下次还能用
```

## 用「说人话」写技术文档

```text
/plain on
/plain level novel
```

然后把要解释的东西丢过去。想让代码和报错保持原样，不用额外说 —— 它们在不动区里。

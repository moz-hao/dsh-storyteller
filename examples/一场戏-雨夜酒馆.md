# 一场戏：雨夜酒馆

把下面几行依次粘进输入框（`@` 后面换成你自己的路径）。

```text
/tavern on
/tavern card @D:\deepseek\chat\dsh-storyteller\examples\角色卡-艾琳.json
/tavern set persona 一个刚进城的外乡人，身上只有一把旧刀，刀鞘上刻着别人的名字
```

`/tavern on` 之后不会直接开演：会先弹一组设定卡片，问世界与年代、你是谁、主 NPC、文风视角、尺度、篇幅。**选完才开戏**，没选的不许它自己编。

想让它直接按你脑子里的画面走，就先把设定写好再开：

```text
/tavern set scene 雨夜的酒馆。后厨门开着，风把灯吹得直晃；门边站着两个人，其中一个在滴水
/tavern style tone=冷硬，带一点戏谑
/tavern setup done
```

第一句自己给，别让它替你选：

```text
我推门进去，把刀放在吧台上，说：来壶热的。
```

之后每回合是固定的三段：正文 → 一行 `【状态】` → 5–8 个选项卡片。选项都能点，也能自己写一句。

三个回合后可以把人设里藏着的钩子甩出来：

```text
我把刀鞘转过来，让那行刻字对着她。
```

想要更狠的尺度：

```text
/tavern erotic on
```

打开之后剧情以色情驱动，每回合至少 2 个选项是色情导向的；不想了 `/tavern erotic off`。

想看模型到底拿到了什么：

```text
/tavern preview
```

收尾：

```text
/tavern reset          # 清这一场，角色卡留着，设定回到待确认
```

---

## 用「说人话」写技术文档

```text
/plain on
/plain level novel
```

然后把要解释的东西丢过去。代码和报错在不动区，不会被改坏。

## 换英文

```text
/tavern lang en
```

提示词、状态摘要、回执一起换；`/tavern lang zh` 换回来。
